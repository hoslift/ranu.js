# Ranu.js Developer Tooling

Developer experience, debugging, diagnostics, and build inspection tools for Ranu.js.

---

## 📦 Installation

### From the Command Line:
```bash
# Install tools suite from GitHub Packages
npm install @hoslift/tools --registry=https://npm.pkg.github.com
```

### Via package.json:
```json
{
  "dependencies": {
    "@hoslift/tools": "^0.4.0"
  }
}
```

---

## Modules

- **Inspector**: Runtime state and memory inspector HUD.
- **Debugger**: Request/Response stream tracing and server actions debugging.
- **Analyzer**: Bundle size analyzer and tree-shaking optimization inspector.
