# Ranu.js Ecosystem Integrations

Community and partner connectors for third-party databases, auth, payments, and mail services.

---

## 📦 Installation

### From the Command Line:
```bash
# Install the integrations suite from GitHub Packages
npm install @hoslift/integrations --registry=https://npm.pkg.github.com
```

### Via package.json:
```json
{
  "dependencies": {
    "@hoslift/integrations": "^0.4.0"
  }
}
```

---

## Supported Integrations

- **Supabase**: Database, Authentication & Realtime subscriptions.
- **Stripe**: Billing, Checkout sessions & Webhooks.
- **Resend**: Transactional emails.
- **MongoDB**: ODM & Database client connection.
