# Ranu.js Production Starter Kits

Production-ready application starter kits for Ranu.js full-stack framework.

---

## 📦 Installation & Usage

### From the Command Line:
```bash
# Scaffold any starter kit interactively
npm create ranujs@latest

# Or install the templates meta-suite from GitHub Packages
npm install @hoslift/templates --registry=https://npm.pkg.github.com
```

### Via package.json:
```json
{
  "dependencies": {
    "@hoslift/templates": "^0.4.0"
  }
}
```

---

## Available Starter Kits

- **SaaS Starter** (`templates/saas`): Drizzle ORM, Authentication, and Stripe billing.
- **AI Studio** (`templates/ai-studio`): Multi-provider AI workbench.
- **Ecommerce Storefront** (`templates/ecommerce`): Fast shopping experience.
- **Admin Dashboard** (`templates/dashboard`): Real-time analytics and tables.
- **Content Blog** (`templates/blog`): SSG / Markdown content engine.
