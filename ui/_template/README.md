## Getting Started

1. Copy this `_template` directory to `ui/<component-name>` (e.g. `ui/components`).
2. Update `package.json`:
   - Set `"name": "@ranujs/ui-<component-name>"`.
   - Set `"author": "Your Name (https://github.com/your-username)"`.
   - Set `"private": false`.
3. Submit a **Module Submission & Certification Request** issue on GitHub.
4. Once reviewed and approved, your UI package will be certified and published!
