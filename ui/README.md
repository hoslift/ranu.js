# Ranu.js UI System

Pre-built accessible React 19 design system, widgets, layout shells, and theme controllers.

---

## 📦 Installation

### From the Command Line:
```bash
# Install UI suite from GitHub Packages
npm install @hoslift/ui --registry=https://npm.pkg.github.com
```

### Via package.json:
```json
{
  "dependencies": {
    "@hoslift/ui": "^0.4.0"
  }
}
```

---

## Modules

- **Components**: Accessible core UI widgets (Buttons, Modals, Forms, Navigation).
- **Themes**: Dark/Light mode theme engine and CSS variable tokens.
- **Layouts**: Responsive application and marketing page shells.
