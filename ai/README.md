# Ranu.js AI Providers & Integrations

Official native AI model integrations for Ranu.js React 19 full-stack applications.

---

## 📦 Installation

### From the Command Line (npm):
```bash
# Standard install via Core
npm install @ranujs/core

# Or install the AI suite from GitHub Packages
npm install @hoslift/ai --registry=https://npm.pkg.github.com
```

### Via package.json:
```json
{
  "dependencies": {
    "@hoslift/ai": "^0.4.0"
  }
}
```

---

## Supported AI Providers

- **Google DeepMind Gemini**: Gemini 2.5 Flash & Pro with native multimodality.
- **Anthropic Claude**: Claude 3.5 Sonnet with prompt caching and tool calling.
- **OpenAI & Codex**: GPT-4o and o1 reasoning models.
- **Groq**: Ultra-low-latency LPU inference.
- **Ollama**: Offline, zero-telemetry local AI runner.
