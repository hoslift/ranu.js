# create-ranu

Create a new Ranu.js project.

> ⚠️ **Pre-alpha**: Not yet functional.

## Usage (coming soon)

```bash
npm create Ranu.js@latest my-app
# or
npx create-ranu my-app
```

Generated apps include:
- TypeScript-first structure
- `app/` directory with `layout.tsx` and `page.tsx`
- `ranu.config.ts`
- `package.json` with `dev`, `build`, `start` scripts
