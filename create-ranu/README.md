# @hoslift/create-ranu

Scaffolding CLI for creating new Ranu.js applications.

> **Public Alpha (v0.1.2)**: Official project initializer for Ranu.js.

## Usage

```bash
npm create @hoslift/ranu@latest my-app
# or
npx @hoslift/create-ranu my-app
```

Generated apps include:
- TypeScript-first structure
- `app/` directory with `layout.tsx` and `page.tsx`
- `ranu.config.ts`
- `package.json` with `dev`, `build`, `start` scripts
